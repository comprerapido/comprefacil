# ⚡ Compre Rápido

**Encontre Rápido. Compre Melhor.**

O Compre Rápido é um portal de inteligência de compras que monitora o mercado em tempo real para trazer as melhores ofertas antes que acabem.

## Sobre o Projeto

- Monitoramento contínuo de preços em marketplaces brasileiros
- Curadoria independente de ofertas com descontos reais
- Guias de compra e rankings atualizados semanalmente
- Totalmente gratuito para o consumidor

## Tecnologias

- HTML5, CSS3, JavaScript (Vanilla)
- GitHub Pages para hospedagem
- JSON como banco de dados estático

## Páginas

- `/` — Página inicial com achados relâmpago
- `/ofertas-hoje/` — Todos os achados do dia
- `/categorias/` — Explorar por categoria
- `/melhores-2026/` — Rankings top 2026
- `/guias/` — Guias de compra
- `/sobre/` — Sobre o Compre Rápido
- `/metodologia/` — Nossa metodologia
- `/contato/` — Fale conosco
